# P2PCLI

点对点远程终端。输入另一台电脑的设备码和配对密码，对方点同意，就能在软件窗口里用它的终端。claude、codex 这类命令行 AI 直接用对方电脑上的账号和环境跑。

- **直连优先**：IPv6 直连 > IPv4 打洞 > 中继兜底，全程端到端加密，中继看不到内容
- **像远程桌面一样配对**：9 位设备码 + 6 位配对密码，密码对了还要对方点允许；同一局域网里不用设备码
- **多标签终端**：断线、关软件后会话还在后台跑，重连接着用
- **认得会话里的 AI**：显示是哪个 AI、在干活还是在等你确认，需要你时提醒你；终端下面有输入框，打完一整句再发
- **代码编辑器**：直接改对方电脑上的文件，带补全、跳转、报错和 Git 面板
- **传文件、端口转发、远程控制**：拖进终端就能发文件；对方的开发服务器一键转发到本机；能看、能操作对方的屏幕，两边剪贴板互通（文字、图片、文件，不限大小）
- **借网、反向端口转发**：对方上不了外网时，一键把本机代理借给它新开的终端；本机的端口也能接到对方电脑上
- **用本机 VS Code 打开**：VS Code、Cursor 的 Remote-SSH 经 P2PCLI 连过去；对方是 Mac、Linux 时不用开远程登录、不用密码
- **命令行工具 `p2pcli`**：在终端里对别的设备传文件、跑命令、读改文件，本机的 AI 也会用；`p2pcli mcp` 给 Cursor、Claude Desktop、Cline 这类 AI 用，还能截对方屏幕给 AI 看

## 下载和安装

到 [Releases](../../releases) 下载：

| 系统 | 安装包 |
| --- | --- |
| macOS 15 及以上 | Apple 芯片 `P2PCLI_x.y.z_aarch64.dmg`，Intel 芯片 `P2PCLI_x.y.z_x64.dmg` |
| Windows 10 及以上 | 大多数电脑 `P2PCLI_x.y.z_x64-setup.exe`，骁龙等 ARM 芯片 `P2PCLI_x.y.z_arm64-setup.exe`，32 位系统 `P2PCLI_x.y.z_x86-setup.exe` |
| Linux（x64 / ARM64） | `.AppImage`、`.deb`、`.rpm`，见 [Linux 桌面支持](docs/linux-desktop.md) |

不知道选哪个：Mac 看 苹果菜单 → 关于本机 的芯片一栏；Windows 看 设置 → 系统 → 系统信息 的系统类型一栏。

装好以后软件会自己检查更新，有新版本在主界面点“更新并重启”就行。

安装包没有付费签名，第一次打开要放行一次：

- **macOS**：双击打开，弹窗里只有 完成 和 移到废纸篓，点 完成；再到 系统设置 → 隐私与安全性，往下翻到「安全性」点 仍要打开，输入开机密码；又弹一次窗，点 仍要打开。看不到 仍要打开 时先再双击一次 P2PCLI，这个按钮只在被拦下后一小时内出现
- **Windows**：提示 Windows 已保护你的电脑，点 更多信息 → 仍要运行

## 怎么用

1. 两台电脑都装好、打开 P2PCLI
2. 被连的一方点标题栏右侧的“本机信息”，把设备码和配对密码发给对方（点旁边的锁能把密码固定下来）
3. 连接方点标题栏右侧的加号，填设备码和配对密码，点连接；被连方在弹窗里点允许
4. 连上后就是对方电脑上的终端，点 + 再开一个标签

连过一次的设备会留在左侧，以后点一下就连。更多功能见 [使用说明](docs/usage.md)。
