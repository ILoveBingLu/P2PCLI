P2PCLI 0.1.9

- 内置代码编辑器：在终端旁边直接打开、编辑、保存对方电脑上的文件，不用来回传文件。可以按名字找文件、全项目搜索、新建、重命名、移到废纸篓；文件被终端里的程序或 AI 改过时会提示，不会悄悄覆盖。
- 代码补全、跳转和报错：自动在对方电脑上启动 rust-analyzer、gopls、pyright、TypeScript、clangd 等语言服务，看得到整个项目。还有问题列表、F2 重命名、快速修复和按名字找符号。
- 终端里的文件路径和 localhost 网址可以 ⌘/Ctrl+点击：路径在编辑器里打开并跳到那一行，网址自动转发端口并在本机浏览器打开。
- 端口转发：把对方电脑上跑着的开发服务器接到本机，一键在浏览器里打开。
- Git 面板：查看改动、暂存、提交、推送、拉取。
- 修复关闭设备最后一个标签时连接没有断开的问题。

以上功能需要对方也更新到这个版本，旧版本会提示更新。代码编辑器、端口转发和 Git 面板是新功能，跨设备实机验证仍在进行中。

继续提供 macOS、Windows 和 Linux 安装包及签名更新。Linux 桌面环境与跨设备实机兼容性仍需持续验证，协作功能仍为实验性。
