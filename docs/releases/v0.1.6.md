P2PCLI 0.1.6

- 新增 Linux x64 / ARM64 桌面打包，提供 AppImage、DEB、RPM，内置静态 tmux，无需另装会话组件；修复 AppImage 临时挂载目录导致 CLI 路径失效的问题。
- 新增实验性跨设备、跨会话协作，支持项目、任务、成员、消息和产物；连接协作可选择“全部会话”，确认权限后自动引导 AI 会话登记接入。
- 协作关系保留双向连线；任务被领取、文件实际传输、结果返回、消息送达时显示对应方向的光点。离线关系保留灰线，可查看详情或移除本机记录。
- 修复多网卡环境的局域网设备发现，支持自动刷新附近设备。
- 会话右键支持清除终端内容，并修复旧缓存回显。
- 文件传输进度按接收端实际收到的数据更新，补充传输诊断。
- 完善跨平台条件编译、权限提示和会话组件管理，清理无用导入及变量警告。

Linux 首次发行，桌面环境、安装格式更新及 Windows / Mac 跨设备实机验收仍待完善。协作功能仍为实验性，自动接入不代表 AI 已完成任务；任务领取、执行、回报和验收需核对真实状态。
