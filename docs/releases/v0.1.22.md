P2PCLI 0.1.22

- 修复「用本机 VS Code 打开」连 Mac 时每次都要输 SSH 密码：0.1.21 里对方 Mac 上 P2PCLI 自己的 SSH 服务起不来（数据目录路径带空格），只能退回系统的「远程登录」，所以要密码。现在不用开远程登录、不用密码。被连的 Mac 要更新到这个版本。
- 连接时不再弹出确认对方主机密钥（指纹）的提示，对方在系统 SSH 服务和 P2PCLI 的 SSH 服务之间切换时也不会被「主机密钥已改变」挡住。认对方是谁由 P2PCLI 的加密连接负责。
- 本机 ssh-agent 里密钥很多时，也不会因为试满次数被对方断开。
- 「用本机 VS Code 打开」可以直接浏览、点选对方电脑上的文件夹，不用手输路径；每台设备记住上次打开的位置。

手机端目前是预览版：iPhone 安装包没有签名，需要用 AltStore、SideStore 或自己的开发者证书签名后安装。电脑端继续提供 macOS、Windows 和 Linux 安装包及签名更新。
