P2PCLI 0.1.15

- 新增远程控制：能看、能操作对方电脑的屏幕。点左侧的设备，在右边设备页点“远程控制”，或者在设备上右键选“远程控制”，会在单独的窗口里打开。对方要是 macOS 或 Windows，两边都要更新到这个版本。
- 抓屏、编码、解码都用两边电脑的显卡，几乎不占 CPU；两边显卡都支持时自动用 H.265，画面更清楚、更省流量，不支持就用 H.264。画质分清晰、均衡、流畅三档，清晰档直接用最高码率。
- 画面只走直连（IPv6、IPv4 打洞、局域网），不走中继：连接落到中继上时画面暂停，终端照常能用，直连恢复后自动接着放。
- 操作对方时鼠标指针在本机画，手一动就跟着动；键盘按键位发送，Mac 和 Windows 之间 ⌘ 和 Ctrl 自动对调。窗口标题栏可以查看连接状态：线路、延时、帧率、码率、编码格式。
- 被看的一方：受信设备直接打开，别的设备要在弹窗里点允许，可以只让看、不让操作；有人在看时标题栏右边一直亮着，随时可以停止；设置 → 远程控制 里可以关掉这个功能或只允许看。macOS 第一次要在系统设置里给 P2PCLI 打开“录屏与系统录音”和“辅助功能”。
- 修复 Windows 上打开代码编辑器窗口可能卡住、关不掉的问题。

手机端目前是预览版：iPhone 安装包没有签名，需要用 AltStore、SideStore 或自己的开发者证书签名后安装。电脑端继续提供 macOS、Windows 和 Linux 安装包及签名更新。
