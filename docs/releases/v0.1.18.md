P2PCLI 0.1.18

- 远程控制时两台电脑的剪贴板互通：文字、带格式的文字、图片、文件和文件夹都能在两边之间复制粘贴，不限大小。复制时只告诉对方有什么，真正粘贴时才传，不卡画面和键鼠。两边都是 Windows 或都是 Mac 时，Excel、Office 这类程序自己的格式也原样带过去。只看不操作时不互通；画面窗口的工具栏上可以关掉。两边都要更新到这个版本。
- Windows 上粘贴对方复制的文件：资源管理器里边传边写、显示进度；只认真实文件路径的程序（比如部分聊天软件）暂时粘贴不进去。Mac 上粘贴对方的大文件时，传完之前 P2PCLI 会暂时没有响应。
- Windows 托盘图标：左键单击直接打开主窗口，右键出菜单。

手机端目前是预览版：iPhone 安装包没有签名，需要用 AltStore、SideStore 或自己的开发者证书签名后安装。电脑端继续提供 macOS、Windows 和 Linux 安装包及签名更新。
