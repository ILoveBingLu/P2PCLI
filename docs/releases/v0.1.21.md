P2PCLI 0.1.21

- 给 Cursor、Claude Desktop、Cline 等 AI 用的 MCP 服务：`p2pcli mcp`。把 设置 → 多机互动 里的 MCP 配置加进它们的 MCP 设置，它们就能直接列设备、在别的电脑上跑命令、读写和搜索文件、传文件，还能截一张对方屏幕的图看界面。截屏和看远程画面一样要对方同意（受信设备按它的设置），截完会通知屏幕的主人。
- 用本机 VS Code / Cursor 打开别的电脑上的文件夹：在左侧设备上右键选「用本机 VS Code 打开…」，经 P2P 走 SSH（Remote-SSH），不用公网地址，也不用改路由器。对方是 Mac 或 Linux 时不用开系统的「远程登录」、不用密码，P2PCLI 自己起一个只给你用的 SSH 服务；对方是 Windows 时要装好「OpenSSH 服务器」。两边都要更新到这个版本。
- 新命令 `p2pcli pipe`：给 OpenSSH 当 ProxyCommand 用，也能把对方电脑上的任意端口接到标准输入输出。
- 端口转发不再跟着终端标签走：关掉标签、网络断了都不停，有连接进来时自动重连。点转发旁边的图钉记住，本机端口固定下来，下次打开 P2PCLI 自动恢复。手动转发时可以指定本机端口。借网关掉终端标签也不停。
- 借网、端口转发放进了设备的右键菜单，不开终端标签也能用；正在转发、正在借网的设备旁边有图标。
- 修复：Windows 版装给本机 AI 的使用说明（SKILL.md）换行不对，有的 AI 可能读不出开头的说明。

手机端目前是预览版：iPhone 安装包没有签名，需要用 AltStore、SideStore 或自己的开发者证书签名后安装。电脑端继续提供 macOS、Windows 和 Linux 安装包及签名更新。
