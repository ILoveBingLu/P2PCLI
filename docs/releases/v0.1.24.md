P2PCLI 0.1.24

- 远程画面带声音：能听到对方电脑正在放的声音（Mac 和 Windows 都行，不用装驱动），工具栏可以静音，静音时对方不录、不占带宽。窗口刚打开时点一下画面才会出声。
- 帧率不再封顶 60：跟着两边屏幕的刷新率走，两边都是 144 Hz 就是 144 帧（Windows 被看时要 Windows 11 24H2 或更新）。
- 清晰档按屏幕的实际像素传，Retina、4K 屏不再缩小；两边都用 H.265 时 5K、6K 屏也不缩小。
- 4:4:4 色彩改成真正的 4:4:4：两边显卡都支持 H.265 的 4:4:4 时才用（比如被看的是装 NVIDIA 显卡的 Windows），不支持就是 4:2:0，连接详情里照实显示。
- Mac 和 Windows 之间的快捷键按本机习惯来：⌘C / Ctrl+C、⌘← 到行首 / Home、⌥← 按词跳 / Ctrl+←、⌘Q / Alt+F4 都会换成对方的按法；对方 Mac 前台是终端时 Ctrl 还是 Ctrl。工具栏的键盘按钮可以关掉。
- 远程控制时可以送一段文字过去（用本机输入法打，对方没装中文输入法也能输）、锁定鼠标玩第一人称游戏、把文件拖进画面窗口直接发过去。
- 连接详情里能看到对方用的编码器（硬件还是软件）、延迟估计和首帧用时；对方显示器关着、一直没画面时会提示。
- 网络诊断能认出路由器把内网 IPv6（fd 开头）转换成公网出去的网络，不再误报没有 IPv6，这种网络也能用 IPv6 直连；只有内网 IPv6 时会说明原因和怎么在路由器里打开。
- 新增 Windows 便携版（x64、ARM64、32 位的 zip）：解压后双击 p2pcli-app.exe 就能用，数据放在旁边的 data 文件夹，可以拷到 U 盘带着走，不往系统里写东西；有新版时提示去发布页下载。
- 以上远程画面的新功能要两边都更新到这个版本。

手机端目前是预览版：iPhone 安装包没有签名，需要用 AltStore、SideStore 或自己的开发者证书签名后安装。电脑端继续提供 macOS、Windows 和 Linux 安装包及签名更新。
