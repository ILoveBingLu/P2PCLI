P2PCLI 0.1.17

- 连到 Mac、Linux 上的终端，往上翻历史不再一格一顿：历史放在本机，滚动、选字不走网络。两边都要更新到这个版本；连 Windows 照旧。
- 修复远程控制时鼠标悬停、滚轮不起作用（只有点击有反应）的问题；滚轮落在鼠标所在的窗口上。
- 远程画面全屏时，顶部正中留一个小拉手，鼠标移上去或点一下工具栏就出来。修复 Windows 上全屏后工具栏出不来、退不出全屏的问题。
- Mac 第一次打开时引导开启远程控制要的录屏、辅助功能两项权限；设置 → 远程控制 里也能开。
- Mac 安装包换成固定证书签名：从这个版本起，以后更新不用再重新给录屏、辅助功能权限。这次更新还需要再给一次。
- 新的启动画面。
- 设置里说明两台牵线服务器（国内服务器、Cloudflare）的登记不互通：两边要选同一台才能用设备码互相找到，换服务器后设备码也会变。“没有这个设备码”的报错也提示了这一点。
- 安卓扫码页加“从相册选择”：二维码在手机自己屏幕上（远程桌面、截图）时也能认。

手机端目前是预览版：iPhone 安装包没有签名，需要用 AltStore、SideStore 或自己的开发者证书签名后安装。电脑端继续提供 macOS、Windows 和 Linux 安装包及签名更新。
